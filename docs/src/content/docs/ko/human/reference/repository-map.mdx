## Kernel

- `crates/kernel/sdk`: module contract, context, message, event, effect, origin,
  deterministic environment, `StateRoot`, 공유 snapshot codec(`sdk::codec`).
- `crates/kernel/host`: registry, dispatch, follow-up drain, block commit/abort
  lifecycle, global root-hash composition, non-deterministic worker
  seam(`host::worker`).
- `crates/kernel/node`: host와 orderer 사이의 loopback 및 ordered node seam.
- `crates/kernel/consensus`: commonware Simplex orderer, content store, relay,
  finalized inbox, resolver fetch, scheme boundary.
- `crates/kernel/statesync`: network state-sync wire protocol과 p2p binding.
- `crates/kernel/recovery`: restart durability — op journal, checkpoint,
  boot-time replay.
- `crates/kernel/indexer`: finalized op stream에서 파생되는 node-local read
  index. root-hash에는 절대 포함되지 않는다.
- `crates/system/capability-host`: capability seam 뒤의 machine-local executor
  provider.

## System

- `crates/system/kv`: QMDB byte-key value module.
- `crates/system/valset`: ed25519 validator membership module.
- `crates/system/saga`: async workflow의 deterministic continuation state.
- `crates/system/governance`: valset 위의 validator-set governance.
- `crates/system/identity`: canonical account, member key, display name, node
  binding.
- `crates/duckdns`: `<handle>.duck` → AccountId naming. module이 아니라
  LIBRARY다 — `gateway` module이 이걸 품고 on-chain 절반을 소유한다.
- `crates/system/wireguard`: validator-set 기반 WireGuard tunnel-upgrade
  protocol. `wireguard::effect`가 apply layer다.
- `crates/system/nat-traversal`, `reachability`, `data-plane`, `overlay-net`:
  hole punch, WireGuard mesh orchestrator, off-consensus byte transport,
  overlay seam.
- `crates/system/lifecycle`, `capability`, `dispatch`, `tagging`: module code
  registry, executor capability, capability-routed dispatch, engagement routing.
- `crates/kernel/blobstore`: node-local content-addressed blob store, 어느 root에도
  들어가지 않는다. `crates/modules/system/gateway`: `.duck` gateway route state.
- wire surface: 각 module이 types-only payload와 query shape를 crate root(`src/interface.rs`)에 공개한다.

## Apps

- `crates/apps/forge`: git-backed project state.
- `crates/apps/pages`: QMDB 위 nested block page와 comment.
- `crates/apps/chat`: QMDB 위 storage-owning chat module, hook fan-out 포함.
- `crates/apps/agent`: agent registry, channel watch, run record.
- `crates/apps/tasks`: 작은 canonical task state.
- `crates/apps/vaults`: 복제되는 opaque secret ciphertext.
- `crates/apps/inbox`: follow-up으로 배달되는 per-member notification queue.
- `crates/apps/automations`: chat hook seam 위의 operator rule.
- `crates/apps/files`: node-local chunk byte 위의 consensus file manifest.
- `crates/apps/jobs`: consensus-native work board.
- app wire surface: crate-root type이 합법적인 cross-module payload surface다.

## Examples and Binaries

- `crates/examples/directory`: state-based directory module. `bin/node`에
  production canary로 등록되어 있다.
- `crates/examples/greeter`: follow-up write를 emit하는 demo module.
- `crates/examples/evm`: QMDB-backed experimental EVM module.
  `noded`/`simnode` genesis에 등록되어 있다.
- `bin/demo`: registered module set의 in-process walkthrough.
- `bin/node`: real-socket validator process와 two-process demo.
- `bin/noded`: app HTTP/WebSocket surface 뒤의 daemon.
- `bin/simnode`: deterministic scenario node — test-scripted block producer 위의
  noded `/v1` wire.
- `bin/fs`: `ducktape-fs`, duckfs working-copy CLI(FUSE는 feature gate).
- `bin/coordinator`: public/private rendezvous·STUN helper.
