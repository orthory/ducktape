core architecture와 live control plane은 자리 잡았다. network state sync, epoch
cutover가 있는 dynamic valset orchestration, governed private network는 node e2e
suite(`cargo test -p node-bin --test cluster_e2e`)에서 real socket 위로 실행된다.
human-runnable invite/join/admit ceremony는 `bin/node/examples/demo-invite.sh`에
있다. 남은 일은 durability edge, demotion behavior, WireGuard runtime wiring,
product depth다.

## Done (was open)

- **Network state sync.** running validator는 state-sync wire protocol(manifest,
  chunked snapshot, `serve_sync`를 통한 live qmdb op-range serving)을 serve한다.
  joiner는 모든 module을 그 위에서 rebuild하고 source app-hash를 합성한다.
- **Dynamic valset orchestration.** `ValsetOrchestrator`는 finalized valset state를
  watch하고 deterministic cutover를 schedule하며, new participant set 위로 engine을
  respawn하고 channel을 rotate한다.
- **Governance and vaults.** member-gated proposal이 membership을 drive하고, vault는
  owner-gated write integrity를 가진 opaque secret ciphertext를 replicate한다.
- **duckfs (real filesystem으로서의 files).** Phase 1–2 shipped. `files` module은
  이제 consensus-replicated, copy-on-write, content-addressed filesystem이다 —
  모든 byte가 restart를 견디는 consensus state이고, staged upload, atomic
  per-path-CAS commit, pinned snapshot, snapshot-addressed read,
  full possession까지 가는 resolver-backed state sync, noded HTTP surface를
  갖췄다. `memory` module은 제거되었다 — duckfs가 흡수했다(generation은
  snapshot이 되고, `duck://memory/...` URI는 `duck://files/...`가 되었다).
  client stack — checkout/commit engine, CLI, FUSE mount — 도 구현되어 있다.
  남은 일은 duckfs 위의 app FilesView product integration이다.

## Durability And Promotion

- ~~Restart/recovery from persisted state~~: shipped. write-ahead op journal과
  periodic checkpoint가 composed app-hash를 boot에서 recover하고, engine은 persisted
  epoch와 finalization floor 뒤에서 기존 journal partition으로 respawn한다. 남은
  edge는 checkpoint 없는 pre-recovery storage dir이 migrate되지 않고 loud failure로
  끝나는 것이다.
- cutover에서 demoted validator는 현재 halt한다. sync-server로 degrade해야 한다.
- replicated state의 per-origin replay nonce. byte-identical frame의 cross-epoch
  replay는 현재 per-engine finalization dedup에만 걸린다.

## Product Depth

- Origin-bound message authorship. signed frame은 authenticated origin을 제공하지만,
  product-level author string은 아직 caller-supplied다.
- 기본 agent/runs/dispatch/jobs loop는 live node에 등록되어 있다. 남은 product
  depth는 더 풍부한 app UX, packaged agent와 harness, 더 넓은 action vocabulary,
  debug surface가 아니라 native하게 느껴지는 durable task obligation이다.

## Mesh

mesh contract는 이제 하나의 crate에 있다. `valset::mesh`는 삭제됐고
`crates/system/wireguard`가 tunnel-upgrade protocol을 소유하며, node의
reachability plane이 runtime에 이를 drive한다. 남은 것은 실제 WireGuard
interface를 올리는 privileged e2e이고, 아직 deliberately descoped다.

## Deferred Deliberately

- commit-phase crash safety와 full two-phase commit은 deferred 상태다. 현재
  host-lent atomicity가 execute-phase behavior를 커버하고, commit-phase fault는 silent
  corruption이 아니라 fail-stop `SubmitError::Fatal`이기 때문이다.
