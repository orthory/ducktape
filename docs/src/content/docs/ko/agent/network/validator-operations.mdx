Ducktape는 propagation, ordered consensus delivery, validator membership을 분리한다.
docs나 code에서 이 개념들을 합치지 않는다.

## Propagation

`crates/kernel/node`에는 deterministic local convergence test에 쓰이는 loopback
transport seam이 있다. QMDB root order를 위한 load-bearing path는 아니다.

## Ordered Path

`OrderedNode<O>`는 `Orderer`의 finalized operation을 apply한다. commonware Simplex
orderer는 `crates/kernel/consensus`에 있고, `bin/node`는 이를 real-socket validator
process로 연결한다.

ordered path는 QMDB root가 write order에 의존하기 때문에 필요하다.

## Membership

`crates/system/valset`은 validator membership을 module state로 저장한다. dynamic
valset path는 finalized valset state를 consensus epoch cutover, transport readiness,
state-sync readiness에 연결한다.

membership behavior를 수정할 때는 respawn, joiner incorporation, finalized epoch
boundary 주변 test를 확인한다.
