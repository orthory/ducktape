## Kernel

- `crates/kernel/sdk`: module contract, deterministic system API, 공유
  snapshot codec(`sdk::codec`).
- `crates/kernel/host`: registry, dispatch, follow-up drain, commit/abort,
  global app-hash composition, worker seam(`host::worker`).
- `crates/kernel/node`: loopback 및 ordered node seam.
- `crates/kernel/consensus`: Simplex orderer, content store, relay, inbox,
  resolver fetch, scheme boundary.
- `crates/kernel/statesync`: state-sync wire protocol과 p2p binding.
- `crates/kernel/recovery`: op journal, checkpoint, boot-time replay.
- `crates/kernel/indexer`: 파생 node-local read index. app-hash에 포함되지
  않는다.
- `crates/system/capability-host`: machine-local executor provider.

## System

- `crates/system/kv`: QMDB byte-key module.
- `crates/system/valset`: validator membership state.
- `crates/system/saga`: deterministic continuation state.
- `crates/system/governance`: valset 위의 validator-set governance.
- `crates/system/identity`: canonical account, member key, display name, node
  binding.
- `crates/system/duckdns`: optional `<handle>.duck` → AccountId naming. node나
  service directory는 없다.
- `crates/system/wireguard`: WireGuard tunnel-upgrade protocol.
  `wireguard::effect`가 apply layer다.
- `crates/system/nat-traversal`, `reachability`, `data-plane`, `overlay-net`:
  hole punch, WireGuard mesh orchestrator, off-consensus byte transport,
  overlay seam.
- `crates/system/lifecycle`, `capability`, `dispatch`, `tagging`: module code
  registry, capability registry, capability-routed dispatch, engagement routing.
- `crates/system/blobstore`, `gateway`, `dispatch-oracle`: node-local blob
  store, `.duck` gateway route state, host-side dispatch worker.
- `crates/duckfs/client`: OS-side duckfs checkout/commit engine — chunk
  hashing, versioned `.duckfs` index, worktree scan/status, change planning, 그리고
  sync `NodeApi` transport(HTTP). consensus path에는 절대 오르지 않는다.
- wire surface: 각 module의 typed payload와 query shape는 crate root(`src/interface.rs`)에 있다.

## Apps

- `crates/apps/pages`: QMDB page tree, block, comment.
- `crates/apps/forge`: git-backed project state.
- `crates/apps/chat`: hook fan-out을 갖춘 storage-owning chat module.
- `crates/apps/agent`: agent registry, watch, run record.
- `crates/apps/tasks`: 작은 canonical task state.
- `crates/apps/vaults`: 복제되는 opaque secret ciphertext.
- `crates/apps/inbox`: per-member notification queue.
- `crates/apps/automations`: chat hook seam 위의 operator rule.
- `crates/apps/files`: node-local chunk byte 위의 consensus manifest.
- `crates/apps/jobs`: consensus-native work board.

## Examples and Binaries

- `crates/examples/directory`: state-based directory module. `bin/node`에
  production canary로 등록되어 있다.
- `crates/examples/greeter`: follow-up write를 emit하는 demo module.
- `crates/examples/evm`: QMDB-backed experimental EVM module.
  `noded`/`simnode` genesis에 등록되어 있다.
- `bin/node`: p2p validator/mesh node (noded app surface도 함께 제공).
- `bin/noded`: http/ws app surface 뒤의 single embedded-host daemon.
- `bin/simnode`: deterministic scenario node — test-scripted block producer 위의
  noded `/v1` wire.
- `bin/coordinator`: public/private rendezvous·STUN helper.
- `bin/fs`: `ducktape-fs`, duckfs working-copy CLI — read verb과
  `crates/duckfs/client` 위의 checkout/status/commit/pin loop. `mount`
  verb(FUSE, `src/fuse/`)는 `fuse` cargo feature 뒤에 gate된다 — pinned snapshot
  에서 `NodeApi`로 read-only, `--rw`는 backing checkout 위 — 그래서 default build은
  libfuse/`fuser`를 끌어오지 않는다.
