## QMDB Order

QMDB root는 operation log에 commit한다. 최종 logical map이 같아도 write reorder는
root를 바꿀 수 있다.

## Fixed-Width Keys

commonware streaming resolver는 fixed-width key를 요구한다. QMDB module은 storage
seam에서 logical key를 hash한다.

## Partition IDs

하나의 deterministic runner 안에서 child context는 storage partition을 자동으로
namespace하지 않는다. rebuild test와 module은 distinct partition id가 필요하다.

## Forge Closure

pack indexing은 reachable git object가 모두 존재한다는 증명이 아니다. ref를 이동하기
전에 object closure를 verify한다.

## Runtime Mixing

real transport와 authenticated discovery test는 Tokio에 둔다. test가 의도적으로
runtime integration을 cover하는 경우가 아니면 consensus logic은 deterministic
simulation에 둔다.

## Seed Coverage

`deterministic::Runner::default()`는 seed 42를 사용한다. scheduler-sensitive change는
seed를 sweep한다.
