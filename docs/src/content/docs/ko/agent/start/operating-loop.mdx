---
title: "Operating Loop"
---

agent는 repo evidence에서 작업하고 unrelated worktree state를 change에 섞지 않는다.

## Before Editing

- 현재 path, branch, worktree list를 확인한다.
- task worktree가 이미 맞는 branch라면 새 worktree를 만들지 말고 계속 사용한다.
- publish 또는 `dev` 기준 claim 전 `origin`을 fetch한다.
- summary에 의존하지 말고 수정할 module 또는 docs surface를 직접 읽는다.

## Docs Commands

docs package는 Bun을 사용한다.

```sh
cd docs
bun install
bun run docs:check
```

local viewing:

```sh
cd docs
bun run dev
```

## Rust Commands

platform code를 만지거나 docs claim이 현재 Rust behavior에 의존할 때 실행한다.

```sh
cargo test --workspace
cargo run -p demo
cargo test -p demo --test network_joiner_full
```

## Publishing

docs-only PR update에는 Bun docs check, draft-text scan, 그리고
`git diff --check origin/dev...HEAD`를 PR evidence에 포함한다.
