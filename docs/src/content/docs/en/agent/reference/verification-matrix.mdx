## Docs Only

```sh
cd docs
bun run docs:check
```

Also run:

```sh
git diff --check origin/dev...HEAD
```

Check that `docs/docs` does not exist and that authored docs do not contain
draft markers.

## Platform Code

```sh
cargo test --workspace
cargo clippy -p <crate> --tests --no-deps
cargo check -p files --no-default-features
```

Run the per-crate clippy gate for every touched crate. The `--no-deps` flag is
deliberate: a crate with broad dev-dependencies should not inherit unrelated
version-drift lints from other crates. Do not run tree-wide fmt as a routine
gate; format only touched Rust files. Keep the files crate wasm-readiness gate
green with `cargo check -p files --no-default-features`.

## Demos and State Sync

```sh
cargo run -p demo
cargo test -p demo --test network_joiner_full
cargo test -p node-bin --test cluster_e2e
```

Use these when docs or code claim multi-module convergence, joiner rebuild, or
real-socket ordered node behavior. `bin/node/examples/demo-invite.sh` is the
human-runnable invite/join/admit ceremony; `cluster_e2e` is the automated gate
for the former bash assertion spec.
