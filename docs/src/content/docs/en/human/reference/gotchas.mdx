## QMDB Root Semantics

QMDB roots commit to the operation log. The same final key-value state can have
different roots if produced by a different write order. Do not reorder writes to
make code look cleaner. Do not use QMDB as the small global head map; the global
root-hash must be state-based and idempotent.

## Fixed-Width Sync Keys

Commonware's streaming QMDB resolvers require fixed-width keys. New QMDB modules
should hash logical keys at the seam, as `kv`, `pages`, and `chat` do.

## Storage Partitions

Within one deterministic runner, child contexts do not automatically namespace
storage partitions. Modules and test rebuilds need distinct partition ids.

## Forge Pack Verification

Libgit2 can index partial packs. A matching head over missing objects is a real
failure mode, so forge install must verify object closure before moving refs.

## Runtime Boundaries

Commonware authenticated discovery and real transport tests belong on Tokio.
Consensus logic tests belong in deterministic simulation. Mixing those runtime
models can deadlock or hide schedule bugs.

## Deterministic Seeds

`deterministic::Runner::default()` uses seed 42. Sweep seeded runs when the risk
is scheduler-sensitive.
