# Repository Map

Use this map to find the authoritative surface before editing.

## Kernel

- `crates/kernel/sdk`: module contract and deterministic system API.
- `crates/kernel/state`: global app-hash composition.
- `crates/kernel/host`: registry, dispatch, follow-up drain, commit/abort.
- `crates/kernel/node`: loopback and ordered node seams.
- `crates/kernel/consensus`: Simplex orderer, content store, relay, inbox,
  resolver fetch, scheme boundaries.
- `crates/kernel/reactor`: host-owned worker loop for effects.

## System

- `crates/system/kv`: QMDB byte-key module.
- `crates/system/valset`: validator membership state.
- `crates/system/saga`: deterministic continuation state.
- `crates/system/governance`: validator-set governance over valset.
- wire surfaces: each module's typed payload and query shapes live at its crate root (`src/interface.rs`).

## Apps

- `crates/apps/document`: QMDB document state.
- `crates/apps/forge`: git-backed project state.
- `crates/apps/chat`: storage-owning chat module with hook fan-out.
- `crates/apps/agent`: agent registry, watches, run records.
- `crates/apps/tasks`: small canonical task state.
- `crates/apps/vaults`: replicated opaque secret ciphertext.
- `crates/apps/inbox`: per-member notification queues.
- `crates/apps/automations`: operator rules over the chat hook seam.
- `crates/apps/files`: consensus manifests over node-local chunk bytes.
- `crates/apps/memory`: filesystem-shaped shared agent workspace.
- `crates/apps/jobs`: consensus-native work board.

## Docs

- `docs/pages/en/human`: English human-facing docs.
- `docs/pages/ko/human`: Korean human-facing docs.
- `docs/pages/en/agent`: English agent-facing docs.
- `docs/pages/ko/agent`: Korean agent-facing docs.
