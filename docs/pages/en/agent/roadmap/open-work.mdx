# Open Work

This page tracks implementation gaps that agents should not accidentally present
as finished.

## Live Network State Sync

In-process module sync proofs exist, and `bin/demo/src/state_sync.rs` defines
tested transport-neutral mesh frames with membership validation. A running node
still needs network resolvers that serve and fetch those frames from the live
validator path.

## Dynamic Valset Orchestration

Tests cover respawn behavior around an epoch boundary, and the deterministic
core exists: the tested `ValsetOrchestrator` state machine
(`crates/kernel/consensus/src/valset_orchestrator.rs`) watches finalized valset
state and publishes a deterministic cutover point. The live loop still needs to
stop old orderers, start new epoch instances, and keep transport/state-sync
readiness aligned.

## Snapshot Serving

The capstone joiner test proves rebuild math. A running node still needs a
pause/serve seam for a consistent all-module snapshot at a finalized height.

## Product Depth

Chat and agent modules exist. The agent path still needs real reactor-backed LLM
work so model output is committed as ordered data. A first tasks module is
checked in (`crates/apps/tasks` plus `tasks-interface` and tests); qmdb backing,
a richer task schema, and product wiring into the binaries remain.
