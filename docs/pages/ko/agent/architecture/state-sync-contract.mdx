# State Sync Contract

state sync는 peer byte를 신뢰하지 않고 authenticated commitment에서 module state를
재구축해야 한다.

## Trust Anchor

module root가 trust anchor다. joiner는 target root 또는 root-derived commitment에
대해 verify한 뒤에만 peer가 serve한 data를 받아들일 수 있다.

## QMDB Modules

QMDB root는 operation log에 commit한다. root semantics가 바뀌지 않는 한 sync를
sorted logical key replay로 대체하지 않는다. 새 QMDB module은 sync seam에서 logical
key를 fixed-width storage key로 hash해야 한다.

## Forge

Forge install은 ref를 이동하기 전에 full object closure를 verify해야 한다. libgit2가
partial pack도 index할 수 있기 때문에 pack indexing만으로 충분하지 않다.

## Snapshot Modules

snapshot installer는 local state를 mutate하기 전에 verify해야 한다. malformed
snapshot이 local root를 부분적으로 advance하면 안 된다.

## Proof Surface

`cargo test -p demo --test joiner_rebuilds_global_app_hash`는 in-process module rebuild와
global app-hash composition을 증명한다. `cargo test -p demo --test
network_joiner_full`, `cargo test -p node-bin --test cluster_e2e`,
`cargo test -p node-bin --test invite_e2e`는 running node의 live state-sync wire
위에서도 같은 boundary를 증명한다.
