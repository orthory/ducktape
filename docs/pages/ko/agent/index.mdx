이 track은 Ducktape repository에서 작업하는 coding agent를 위한 것이다. public
architecture를 operating rule로 압축한다. 어떤 file이 authoritative한지, 어떤
command가 claim을 증명하는지, 어떤 invariant를 완화하면 위험한지에 집중한다.

## Working Model

- `crates/kernel/sdk`를 module contract의 source of truth로 본다.
- `crates/kernel/host`와 `crates/kernel/state`를 app-hash boundary로 본다.
- `crates/kernel/consensus`와 `bin/node`를 ordered delivery path로 본다.
- `docs/pages`는 language와 reader로 나뉜 Vocs route tree다.
