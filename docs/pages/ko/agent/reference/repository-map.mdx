# Repository Map

수정 전 authoritative surface를 찾기 위한 map이다.

## Kernel

- `crates/kernel/sdk`: module contract와 deterministic system API.
- `crates/kernel/state`: global app-hash composition.
- `crates/kernel/host`: registry, dispatch, follow-up drain, commit/abort.
- `crates/kernel/node`: loopback 및 ordered node seam.
- `crates/kernel/consensus`: Simplex orderer, content store, relay, inbox,
  resolver fetch, scheme boundary.
- `crates/kernel/reactor`: effect를 위한 host-owned worker loop.

## System

- `crates/system/kv`: QMDB byte-key module.
- `crates/system/valset`: validator membership state.
- `crates/system/saga`: deterministic continuation state.
- `crates/system/governance`: valset 위의 validator-set governance.
- wire surface: 각 module의 typed payload와 query shape는 crate root(`src/interface.rs`)에 있다.

## Apps

- `crates/apps/pages`: QMDB page tree, block, comment.
- `crates/apps/forge`: git-backed project state.
- `crates/apps/chat`: hook fan-out을 갖춘 storage-owning chat module.
- `crates/apps/agent`: agent registry, watch, run record.
- `crates/apps/tasks`: 작은 canonical task state.
- `crates/apps/vaults`: 복제되는 opaque secret ciphertext.
- `crates/apps/inbox`: per-member notification queue.
- `crates/apps/automations`: chat hook seam 위의 operator rule.
- `crates/apps/files`: node-local chunk byte 위의 consensus manifest.
- `crates/apps/memory`: filesystem 모양의 shared agent workspace.
- `crates/apps/jobs`: consensus-native work board.

## Docs

- `docs/pages/en/human`: English human-facing docs.
- `docs/pages/ko/human`: Korean human-facing docs.
- `docs/pages/en/agent`: English agent-facing docs.
- `docs/pages/ko/agent`: Korean agent-facing docs.
