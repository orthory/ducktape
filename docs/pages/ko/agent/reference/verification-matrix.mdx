# Verification Matrix

touched surface를 증명하는 가장 좁은 command set을 사용한다.

## Docs Only

```sh
cd docs
bun run docs:check
```

추가로 실행한다.

```sh
git diff --check origin/main...HEAD
```

`docs/docs`가 없고 authored docs에 draft marker가 없는지 확인한다.

## Platform Code

```sh
cargo test --workspace
cargo fmt --all -- --check
```

특정 module을 바꿀 때 focused test를 실행할 수 있다. 다만 사용자가 narrow run을
명시하지 않았다면 workspace gate를 narrow test로 대체하지 않는다.

## Demos and State Sync

```sh
cargo run -p demo
cargo test -p demo --test joiner_rebuilds_global_app_hash
cd bin/node && ./examples/demo-2node.sh
```

multi-module convergence, joiner rebuild, real-socket ordered node behavior를 claim할
때 이 command를 사용한다.
