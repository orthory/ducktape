# Repository Map

workspace는 platform layer별로 구성되어 있다.

## Kernel

- `crates/kernel/sdk`: module contract, context, message, event, effect, origin,
  deterministic environment, `StateRoot`.
- `crates/kernel/state`: 정렬된 module root 위의 global app-hash composition.
- `crates/kernel/host`: registry, dispatch, follow-up drain, block commit/abort
  lifecycle.
- `crates/kernel/node`: host와 orderer 사이의 loopback 및 ordered node seam.
- `crates/kernel/consensus`: commonware Simplex orderer, content store, relay,
  finalized inbox, resolver fetch, scheme boundary.
- `crates/kernel/reactor`: non-deterministic effect를 위한 host-owned worker loop.

## System

- `crates/system/kv`: QMDB byte-key value module.
- `crates/system/valset`: ed25519 validator membership module.
- `crates/system/saga`: async workflow의 deterministic continuation state.
- `crates/system/governance`: valset 위의 validator-set governance.
- wire surface: 각 module이 types-only payload와 query shape를 crate root(`src/interface.rs`)에 공개한다.

## Apps

- `crates/apps/forge`: git-backed project state.
- `crates/apps/pages`: QMDB 위 nested block page와 comment.
- `crates/apps/chat`: QMDB 위 storage-owning chat module, hook fan-out 포함.
- `crates/apps/agent`: agent registry, channel watch, run record.
- `crates/apps/tasks`: 작은 canonical task state.
- `crates/apps/vaults`: 복제되는 opaque secret ciphertext.
- `crates/apps/inbox`: follow-up으로 배달되는 per-member notification queue.
- `crates/apps/automations`: chat hook seam 위의 operator rule.
- `crates/apps/files`: node-local chunk byte 위의 consensus file manifest.
- `crates/apps/memory`: filesystem 모양의 shared agent workspace.
- `crates/apps/jobs`: consensus-native work board.
- app wire surface: crate-root type이 합법적인 cross-module payload surface다.

## Examples and Binaries

- `crates/examples/directory`: test와 demo에서 쓰는 state-based directory module.
- `crates/examples/greeter`: follow-up write를 emit하는 demo module.
- `bin/demo`: registered module set의 in-process walkthrough.
- `bin/node`: real-socket validator process와 two-process demo.

## Docs

- `docs/`: Vocs project.
- `docs/pages`: language/reader 축으로 나뉜 page tree.
