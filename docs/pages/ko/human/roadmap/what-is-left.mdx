# What Is Left

repo는 core architecture threshold를 넘었다. 남은 일은 live control plane과 그
주변의 product depth다.

## Network State Sync

module sync path는 in-process로 증명되어 있고, `bin/demo/src/state_sync.rs`는
membership validation을 갖춘 transport-neutral mesh request/response frame을
이미 정의하며 test로 검증된다. 아직 빠진 것은 live network path다. in-process
wiring이 아니라 running validator mesh 위에서 이 frame을 serve하고 fetch하는
resolver가 필요하다.

## Dynamic Valset Orchestration

consensus respawn behavior는 epoch boundary에서 joiner를 편입하는 test coverage를
가지며, deterministic core는 완료 상태다. test된 `ValsetOrchestrator` state
machine(`crates/kernel/consensus/src/valset_orchestrator.rs`)이 finalized valset
state를 watch하고 deterministic cutover point를 결정해 publish한다. 남은 일은 그
core 주변의 live wiring이다.

- old orderer instance를 stop하고 new epoch를 일관되게 start한다.
- transport와 state-sync readiness를 membership change와 맞춘다.

state sync는 joiner catch-up의 개념적 blocker가 아니지만, live orchestration은
아직 wiring이 필요하다.

## Live Snapshot Serving

capstone test는 joiner가 module target과 snapshot에서 rebuild할 수 있음을 증명한다.
running node는 finalized height에서 consistent all-module snapshot을 제공하는
pause/serve seam이 아직 필요하다.

## Product Modules

chat과 agent에는 실제 product pressure가 더 필요하다. agent module은 reactor
worker seam에 연결되어야 한다. LLM output은 hidden non-determinism이 아니라
ordered data로 commit되어야 한다. 첫 tasks module은 이미 checked-in 상태다
(`crates/apps/tasks`와 `tasks-interface`, test 포함). staged in-memory state와
검증된 snapshot/install을 갖추고 있고, 남은 일은 qmdb backing, 더 풍부한 task
schema, binary로의 product wiring이다.

## Deferred Deliberately

- commit-phase crash safety와 full two-phase commit은 deferred 상태다. 현재
  host-lent atomicity가 execute-phase behavior를 커버하기 때문이다.
