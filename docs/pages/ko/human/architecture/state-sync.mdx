## QMDB Modules

`kv`, `pages`, `chat` module은 commonware의 QMDB sync engine으로 sync한다. source는
target root와 operation range를 노출한다. joiner는 batch를 pull하고 target root에
대해 merkle-verify한다. logical key를 tidy order로 replay하는 것은 동등하지 않다.
QMDB root는 operation log에 commit하기 때문이다.

QMDB module은 streaming resolver가 fixed-width key type을 요구하기 때문에 storage
seam에서 logical key를 fixed-width key로 hash한다.

## Forge

Forge sync는 git data를 중심으로 동작한다. root는 head object id에서 나오지만,
pack indexing만으로 충분하지 않다. libgit2는 partial pack도 index할 수 있다.
install path는 ref를 이동하기 전에 full-closure connectivity walk를 실행한다.

## Snapshot Modules

Valset, governance, saga, 그리고 state-based product module(tasks, vaults,
agent, inbox, automations, files, memory, jobs, upgrade)은 필요한 곳에서 canonical-byte
snapshot/install path를 사용한다. installer는 local state를 mutate
하기 전에 verify해야 하므로 malformed 또는 incomplete snapshot이 root를 부분적으로
advance할 수 없다.
